# 🌱 AI Crop Disease Assistant

An AI-powered crop disease detection system that analyzes leaf images and provides actionable insights for farmers and researchers.

---

## 🚀 Features

- 🌱 Detects crop diseases from leaf images
- 🧠 CNN-based deep learning model
- 📊 Provides prediction confidence score
- 🚑 Suggests causes and possible solutions
- 💻 Interactive web app using Streamlit

---

## 📊 Model Details

- Architecture: Convolutional Neural Network (CNN)
- Dataset: PlantVillage Dataset (Kaggle)
- Number of Classes: 37
- Accuracy: 93.7%

---

## 🖼️ How It Works

1. Upload a leaf image
2. Model analyzes the image
3. Outputs:
   - Crop name
   - Disease type
   - Confidence score
   - Causes and solutions
